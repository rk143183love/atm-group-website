# ATM GROUPS Website — Admin CMS Plan

The website is designed to use a private `/admin` dashboard for content management so normal visitors do not see editing controls.

## Editable content
- Home / hero
- About
- Services
- Divisions
- Vision & Mission
- Why Choose Us
- Clients
- Licenses / Compliance
- Contact details
- Images and logo

## Deployment
GitHub remains the source repository. The public site can be deployed on Vercel or Netlify. A real persistent admin CMS requires a server-side authentication/data store; secrets must never be placed in browser JavaScript.

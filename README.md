# ATM GROUPS Corporate Website

Professional, modular and content-editable corporate website for ATM GROUPS — Logistics & Manpower Solutions.

## Structure
- `index.html` — page structure
- `content.js` — all editable business content and divisions
- `style.css` — visual system and responsive design
- `admin.html` — browser-based content editor/exporter
- `assets/atm-logo.svg` — ATM GROUPS logo

The supplied company profile is used as information reference; the website layout is a new corporate presentation, not a PDF copy.
